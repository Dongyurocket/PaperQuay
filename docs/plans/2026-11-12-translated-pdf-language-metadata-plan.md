# PaperQuay 译版 PDF 语言元数据设置与补录计划

**Version 1.0.0**

- 日期：2026-11-12（Asia/Shanghai）
- 源码基线：`5fb9961`，PaperQuay 0.4.24
- 状态：已实现并发布 PaperQuay 0.4.25。功能、自动化测试、生产构建、用户手册和 Release Notes 已完成；Windows 安装版的实机交互验收待安装本次 Release 后执行。
- 验收平台：Windows。后续正式发行仅提供 Windows 版本；其他平台由用户自行打包，作者不承担其维护与测试。

## 1. 目标与范围

为译版 PDF 提供可见、可修改、可清除的语言元数据，并支持现有译版批量补录。保存后，文献库与已打开的阅读器立即显示最新语言。

本计划包含四项交付：

1. 在译版附件旁增加“设置语言”，支持首次设置、修改及清除。
2. 对现有译版提供批量设置，保存前展示文献清单、附件、原值及新值。
3. 在附加新译版时增加语言选择，可预填当前翻译目标语言，由用户确认。
4. 保存后更新单栏及对照阅读的译版标签，只修改元数据，保留 PDF 文件、路径与附件关联。

本轮产物仅为计划文档。后续实施应在测试文库验证写入，不自动将用户现有译版全部认定为中文，不根据文件名或界面语言直接回填。

不扩展为论文书目信息编辑、PDF 内容翻译、PDF 内嵌属性改写或文件治理功能。现有附加流程本身所需的文件复制、替换确认仍按既有规则执行；既有附件的语言编辑必须走独立的元数据更新流程。

## 3. 元数据定义与不变量

### 3.1 字段与语言规范

- 语言属于译版附件，以 `attachmentId` 定位；不能仅按论文 ID 推断目标附件。
- 已知语言采用规范化的 BCP 47 语言标签，例如 `zh-CN`、`zh-TW`、`en`、`ja`、`de`、`fr`。
- 提供常用语言下拉项及自定义标签输入。前后端共享一致的规范：去除首尾空白、规范大小写、拒绝非法标签，不将自定义语言压缩为中英两类。
- “清除语言”统一写入 `null`，界面显示“语言待确认”。不能把未选择误作清除，也不能把缺失请求字段误作清除。
- 对历史 `null`、空字符串、`und`、`unknown`、`undefined` 等未知值保持兼容，统一按未知显示。仅在用户明确保存选中目标时规范化写入，不执行启动时全库回填。
- 历史非空且未识别的值在编辑与预览中保留原值并提示检查，不能静默转成中文或其他已知语言。
- 修改全局翻译目标语言不会更改已有附件；其作用限于新附加操作中的默认候选值。

### 3.2 保存时必须保持的内容

除目标附件的 `language`、确有必要的绑定语言镜像和所属文献的 `updatedAt` 外，不改动其他持久化字段。

必须保持：附件 ID、论文 ID、附件角色、文件名、原始路径、存储路径、相对路径、内容哈希、文件大小、创建时间、资产 ID、来源关系，以及笔记、批注和解析/RAG 缓存关联。

语言编辑不读取或重写 PDF 内容，不移动、重命名、复制或删除 PDF，不解绑再附加，不触发翻译、解析或索引重建。文件暂时缺失不妨碍编辑仍存在的附件记录。

## 4. 用户操作流程

### 4.1 单个译版设置、修改与清除

入口位于文献详情中的译版附件旁，操作名称为“设置语言”。已有语言时同时展示可读名称与代码，例如“简体中文（zh-CN）”。

弹窗包含文献标题、附件完整文件名、当前语言、语言选择器和“清除语言”操作。编辑已有附件时默认使用其当前值；未知值不能被全局设置自动覆盖。

用户选择语言后点击“保存”；选择“清除语言”时明确展示结果“语言待确认”，点击保存后才写入。取消及关闭弹窗均不写入。值未变化时提示无需修改，避免无意义写入。

保存期间禁止重复提交；失败时保留输入并展示错误。后端成功后更新附件信息和阅读器标签。

### 4.2 批量设置及保存前预览

文献库多选工具栏增加“设置译版语言”。操作基于用户明确选中的文献枚举译版附件；一篇文献有多个译版时，逐个列出并允许排除。

提供统一的新语言选择以及“清除语言”，默认仅勾选语言未知的译版，已有语言条目默认不勾选，用户可以逐项纳入修改。没有译版的文献列为跳过项并说明原因。

预览至少包含：

| 文献 | 译版附件 | 当前值 | 保存后 | 操作 |
|---|---|---|---|---|
| 示例文献 A | translation-a.pdf | 语言待确认（原值为空） | 简体中文（zh-CN） | 设置 |
| 示例文献 B | translation-b.pdf | 英语（en） | 简体中文（zh-CN） | 修改，默认不勾选 |
| 示例文献 C | translation-c.pdf | 简体中文（zh-CN） | 语言待确认 | 清除 |

上表是流程示例，不是对用户文库的实际改动清单。实际预览应准确反映本次选定动作。

预览显示选中文献数、译版附件数、实际变更数、未变更数及跳过数；用户可查看完整清单，长列表可滚动或虚拟化，不能只展示前若干项便隐藏其余目标。跨页全选必须按完整选择集合枚举，不能只处理当前已加载的一页。

流程为“选择目标 → 选择语言或清除 → 查看并调整预览 → 保存 N 项变更”。选择目标、生成预览和取消均不写入。没有实际变更时禁用保存。

一批更新使用同一数据库事务：全部成功或全部回滚。若预览后附件已被移除、替换或语言发生变化，拒绝整批保存，提示刷新预览，不悄悄覆盖或报告部分成功。

### 4.3 附加新译版时确认语言

文献库和阅读器的附加入口共用语言选择逻辑及文案：

1. 用户选择 PDF 后，展示文献、文件名和语言选择器。
2. 当前翻译目标语言有效时预填，并提示“请确认所选 PDF 的实际语言”；无有效默认值时选择“暂不设置”。
3. 用户可以修改语言或保留未知，点击“附加”才提交附件请求。
4. 保留现有页数差异、替换附件等必要确认；取消任何步骤均不得产生附件写入。
5. 语言随成功附加的附件一并持久化，不出现“附加成功但语言未保存”的中间结果。

相同内容已存在时保留既有去重规则，不隐式更新旧附件的语言；提示“该译版已存在，可通过设置语言修改”，避免附加操作绕过元数据编辑语义。

### 4.4 阅读器即时刷新

单个或批量保存成功后，以后端返回的最新文献数据更新本地状态，并按文献去重发送 `emitNativePaperUpdated`。复用 `createNativeLibraryWorkspaceItem` 等现有映射，保证语言进入项目文件角色和来源标签。

验收覆盖文献库详情、来源下拉菜单、译版单栏、对照阅读和已打开但未激活的标签页。清除后显示“译版 · 语言待确认”；已知语言沿用现有格式，如“译版 · zh-CN”。完整文件名提示保持可用。

仅语言改变时保留所选来源、当前页、滚动位置、缩放、对照开关和同步开关；不能因为重建工作区对象导致 PDF 重新加载或页码复位。

## 5. 后端与接口设计

### 5.1 专用元数据更新能力

建议新增 `library_update_translated_pdf_languages`，由单项及批量界面共用。名称可按仓库约定调整，但不得复用移除、替换或重新附加接口。

请求示意：

```ts
interface UpdateTranslatedPdfLanguagesRequest {
  changes: Array<{
    paperId: string;
    attachmentId: string;
    expectedLanguage: string | null;
    language: string | null;
  }>;
}
```

`expectedLanguage` 为预览时读到的原始字段值，用于事务内并发校验；空字符串与 `null` 在冲突检查时不得混同。`language` 为明确的新值，`null` 表示清除。缺少字段、空变更列表、重复附件 ID、非法标签应在写入前处理或拒绝，不能产生不确定行为。

事务内逐项校验论文与附件归属、附件仍为 `translated-pdf`、当前原值与预览一致，再规范化新值并更新。仅更新实际变化的附件；相同值不改时间戳。返回受影响文献的最新完整数据及实际变更数，供界面刷新。

### 5.2 数据库写入边界

- 在数据库存储层新增专用方法，以参数化 SQL 精确更新 `attachments.language`，并更新实际变更文献的 `updatedAt`。
- 不调用会重建附件及其他关联的 `savePaperToDb` / `replaceRelations` 作为本操作的写入实现。
- 核实 `pdf_attachment_bindings` 的读写关系；若目标附件已存在绑定记录，在同一事务中同步其语言。不得为了补语言创建资产、重建绑定或变更资产身份。
- 预览后的重新校验、所有行更新及返回数据读取应处于一致的事务边界，发生异常必须回滚全部变更。
- 不要求新增数据库列或全库迁移。现有未知值继续可读，用户未选择的附件保持原样。
- 新增附加与元数据更新采用同一语言校验规范；兼容旧客户端省略新增附加请求的语言字段，不能因此破坏既有调用。

桌面 IPC 注册、命令允许列表及类型声明应按实际调用链补齐。现有 MCP 附加接口本轮不新增批量写入工具；若与桌面共享的后端行为受影响，运行其兼容性测试。

## 7. 测试与验收

### 7.1 自动化验证

1. **语言规范**：已知标签、大小写规范化、首尾空白、自定义有效标签、非法值、历史未知值及显式清除。
2. **事务和一致性**：单项修改、批量混合修改、重复目标、附件归属不符、目标非译版、预览后语言变化、附件移除及写入异常。失败时验证零部分写入。
3. **数据不变量**：保存前后比较附件除语言之外的全部字段及关联记录；有绑定时只同步绑定语言，无绑定时不额外创建；PDF 路径、哈希、文件内容和数量不变。
4. **界面行为**：取消不写入、无变化不提交、重复点击只提交一次、清除明确可见、批量已有语言默认不勾选、完整目标枚举、后端冲突后保留可重新预览的状态。
5. **附加行为**：两个入口使用确认值；目标语言只作默认值；未知值可附加；页数差异取消不写入；重复文件不覆盖既有语言。
6. **阅读器回归**：设置与清除立即更新标签；同一文献多处视图一致；页码、滚动位置、缩放、选中来源和对照状态保持；语言变化不增加 PDF 加载任务。

运行与变更直接相关的测试，再执行仓库既定完整检查 `npm run check`。只有测试结果实际通过后才记录为通过，不预填测试数量。

### 7.2 Windows 安装版验收

在独立测试文库中准备未知语言、已知语言、不同译文语言、无译版、多译版、缺失文件及跨页选择样本。不得为验收复制用户的私有文库或自动改写其 29 个附件。

| 场景 | 通过标准 |
|---|---|
| 未知译版设为 `zh-CN` | 保存后详情和已打开阅读器立即显示已知语言，重启后保持。 |
| `zh-CN` 修改为 `ja` | 新值准确保存，各视图一致。 |
| 清除已知语言 | 持久化为 `null`，立即及重启后均显示语言待确认。 |
| 批量补录 | 完整预览可查，未勾选附件不变，成功数等于实际变更数。 |
| 预览期间另一操作修改目标 | 整批拒绝，原批次无任何部分写入，可刷新后重试。 |
| 两个入口附加新译版 | 均可确认或修改默认语言，保存的值与用户选择一致。 |
| 译版重复附加 | 明确说明已存在，不隐式修改语言。 |
| 单栏和对照阅读中修改语言 | 标签更新，页码、缩放及阅读状态保持，没有重新加载闪烁。 |
| 文件与关联检查 | 文件名、路径、内容、附件及资产身份保持；既有阅读、笔记、批注及解析可用。 |

证据记录版本、场景、预期、实际结果及必要截图/结构化对比；不归档私有 PDF。安装版验收结果与自动化测试分别记录。
