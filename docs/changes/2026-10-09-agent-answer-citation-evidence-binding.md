# 2026-10-09 - Agent 回答句子与引用证据绑定

## 现象

Agent 回答中的数字引用能打开真实文献片段，但片段可能并不支持所在句子；原证据统计没有阻止该引用继续可点击。

## 根因

运行内编号唯一化只解决来源身份，未验证句子与来源的语义关系。消息引用集合还包含检索过但回答未使用的材料，渲染层直接按数字生成跳转。

## 修改

- 模型复制本轮 `[[cite:<id>]]`，数字标签由界面从 canonical citation 生成。工具上下文、比较调研、压缩和恢复保留 token 与来源身份。
- 每个引用出现位置保存句子、偏移、状态、原因、核验模型及简短判定。未知/歧义/同句重复引用、显式元数据冲突直接拒绝；证据缺失、短句/问句、数量缺失等保持未验证。
- 规则通过后使用当前 Agent 模型逐对核验，只发送该句与该来源的题名、页码、片段；仅严格 JSON `supported` 可放行。最多 48 对、并发 3、每次 15 秒；网络错误、非法响应、超时、取消均不可点击，超出上限的条目也保持未验证。
- 流式输出和无核验记录的历史数字引用不可点击。确定性能力报告中的旧数字引用也维持 legacy 状态，不静默改写论述或编造对应证据。
- 界面显示核验统计、明细和“核验引用”操作；重新核验使用当前所选模型并记录运行及 token 用量。新结果随消息持久化，分叉复制绑定；恢复 checkpoint 单独保存完整证据，避免工具消息截断丢失片段。
- “已核验证据”仅列出正文实际通过绑定的来源；所有检索材料另行折叠且无证据页跳转按钮。已验证按钮继续传递原 canonical 对象，阅读器定位协议保持不变。

默认启用二次核验，因此最终输出后的延迟和模型费用会增加。模型判定仍可能误判，应以原文为准；程序保证核验失败不放行，不保证模型判断绝对正确。

## 回滚

开发者可设置 `localStorage['pq.agentCitationVerifier'] = 'off'` 停用二次模型调用；删除该键恢复默认。停用后新核验仍执行规则并保持未验证，不恢复数字引用默认可点击。已持久化且符合当前规则的成功绑定继续有效；重新核验时清除旧结果再判定。
