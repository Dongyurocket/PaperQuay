# 2026-11-19 - 外部 Agent 优先：移除独立 Agent、版本化 MCP 写入与问答范围

## 现象

- 独立 Agent 工作区与笔记 AI 润色与阅读器问答职责重叠，维护成本和上下文预算压力都在上升。
- MCP 写入在桌面应用运行时只能整体拒绝，或显式覆盖；文库全量重写会覆盖并发修改，详情表单也可能用旧快照覆盖字段。
- 问答只支持当前文献，引用缺少 `paperId`/证据类型，表格正文未进入索引，多文献时无法控制上下文预算。
- 图谱的人工关系只能新建/删除，AI 关系类型不再需要。

## 修改

- 退役 PaddleOCR-VL，MinerU 的 `isOcr` 重试成为唯一解析/OCR 降级入口；旧缓存按 MinerU 契约继续读取。
- 删除独立 Agent 工作区、其运行时/IPC/记忆与笔记 AI 润色；保留阅读器问答、摘要、翻译、块重解析和选区摘录。
- MCP 文库与笔记写入改为目标记录写 + `expectedUpdatedAt`/预览版本；应用运行时显式 `allowWhileAppRunning: true` 变为受检并行写，冲突返回 `PAPER_CONFLICT` / `CATEGORY_CONFLICT` / `NOTE_CONFLICT`。
- 新增 `preview_delete_papers`、`read_paper_figure`；删除预览校验文献/附件版本，只删受管且未共用的文件。
- 桌面应用监听外部写入标记，刷新列表；脏表单/笔记显示“外部更新”提示。
- 问答支持当前文献 / 选定文献 / 全库范围；引用携带 `paperId`、证据类型；表格索引包含图注与正文；按 QA 模型 `contextWindow` 装箱。
- 笔记 MCP 写入要求版本，正文更新必须保留锚点链接；文件夹级联删除校验所有受影响版本；Vault 同步改为仅手动或用户开启的定时同步。
- 图谱移除 `ai_suggested`，存量关系备份后清理；人工关系支持编辑标签、说明和权重。

## 验证

- `npm run build`、`npm test` 通过。
- 新增定向测试覆盖：旧备份字段规范化、运行时 MCP 写入与冲突、删除预览、外部写入标记、问答范围与预算、笔记版本/锚点、关系清理与更新。
