# 2026-08-26 - 双语标题与翻译版 PDF 对照阅读

## 现象

- 文献记录只有一个标题字段，中文用户无法同时保留英文原标题与中文译名，也无法在列表中切换标题语言。
- 阅读器已有“原版 PDF + MinerU 识别/翻译文本”双栏模式，但不能附加 retainpdf 生成的版式对应翻译 PDF，也不能将两份 PDF 逐页对照。

## 根因

- SQLite `papers` 表、文献类型与更新接口没有独立的中文标题字段。
- 附件存储只提供导入论文主 PDF 的流程，没有为已有论文添加或移除翻译版 PDF 的命令。
- 阅读器双栏布局的右栏固定为 `BlockViewer`，`PdfViewer` 也没有接收外部页码同步信号。

## 修改

### 双语标题

- 为 `papers` 表新增可空列 `title_zh`，启动时通过幂等列迁移兼容旧数据库；读写映射为 `LiteraturePaper.titleZh`。
- 文献详情支持手工编辑中文标题，并可调用现有翻译模型将原标题固定翻译为简体中文后填入表单。
- 文献列表和详情页新增“中英标题 / 中文标题 / 原文标题”显示模式并持久化；双语模式以中文为主标题、英文为副标题，列表与详情保持同步。
- 中文标题纳入真实文献库和演示文献库的搜索。

### 翻译版 PDF

- 新增 `translated-pdf` 附件类型，以及添加、替换、移除已有论文附件的后端命令与渲染层服务。
- 文献详情支持附加、替换、移除 retainpdf 翻译版 PDF；附加前读取原版和翻译版页数，页数不一致时警告但允许继续。
- 同一论文只保留一份翻译版 PDF；替换会清理旧的库内副本，移除不会影响原始 PDF 或用户选择的 retainpdf 源文件。
- 翻译版 PDF 会随 WebDAV 的“包含 PDF”设置进入备份与恢复流程。

### PDF 对照阅读

- 阅读模式新增“PDF 对照”：左侧显示原版 PDF，右侧显示翻译版 PDF；本地文献未附加翻译版时可在右栏直接选择文件。
- 两栏按 1-based 页码双向同步，可随时关闭滚动同步；同步跳页使用即时定位，避免平滑滚动途经中间页时发生反向联动。
- `PdfViewer` 新增外部页码同步信号、实际应用回执和显式页码变化通知；同步 token 会等待目标页 DOM 就绪后消费，工具栏跳页、滚动换页、进入对照模式和翻译版动态替换都会稳定对齐。
- `pdf-compare` 模式写入阅读历史并兼容旧历史记录。
