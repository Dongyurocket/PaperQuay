# 知识图谱 P0：隔离不同来源表示的文档向量

日期：2026-11-12（Asia/Shanghai）

## 实现

`rag_document_vectors` 为查询效率按文献与维度聚合多个来源索引。聚合后的 PDF 文本和 MinerU Markdown 表示不在同一语义空间，不能据此生成跨文献近邻边。现在只有文献在该维度下拥有唯一已就绪 embedding model key，且文档投影恰有一个 sourceType 时才参与比较；两篇文献还必须具有相同的 sourceType。

历史混合表示缓存保留在原存储中，只从相似边投影排除，不执行破坏性清理或隐式重算。它们将在后续明确版本化索引/迁移工作中处理。
