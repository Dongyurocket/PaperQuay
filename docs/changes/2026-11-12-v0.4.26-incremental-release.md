# PaperQuay 0.4.26 阶段发布

## 范围

本次发布包含当前联合实施工作树中的文献工作区改进、P0-T 主题语义样式、共享文件位置服务、图谱知识存储与证据基础、长文档 generation/staging/章节结构、恢复和备份修复。关联的三份计划继续作为实施台账；本版不代表所有范围已完成。

## 尚未验收

- 当前安装版运行中的 PaperQuay MCP 子进程占用原安装可执行文件，NSIS 无法关闭该进程；因此安装后的应用行为、浅/深主题 computed style 与截图、125%/150% 缩放、嵌入/浮动窗口和 Explorer reveal 均未实测。
- 未调用真实 Paddle 或外部模型服务；代表性长文档的结构质量、内存、磁盘和耗时仍待实测。工程手册 PDF.js 基线的复杂表格质量闸门未通过。
- 工作区 P0-T/P0-F 桌面验收及 P1—P7、KG P1/P2、长文档 L0/L1a/L1b/L2/L3 仍按联合台账逐项推进，不以本次自动化通过替代未完成闸门。
