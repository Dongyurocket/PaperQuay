# 2026-09-23 - 文库全选当前筛选（P2-2）

对应方案：`docs/plans/2026-09-23-performance-reader-outline-and-rag-context.md` 的 P2 全选。分页查询沿用 P2-1，本次只接选择模型。

## 现象

- 多选只记住当前已加载行。滚动加载下一页，或列表刷新后，不在这一页里的 id 会被丢掉。
- 因此“全选”实际最多选中已加载的 500 条，旧路径甚至到不了 1000 条以外的匹配。

## 修改

- 工具栏增加全选复选框，文案为当前筛选的匹配总数。三态：未选、部分选择、全选。
- 点击全选时按当前分类和搜索枚举全部文献 id（每页 5000，只取 id），冻结成快照。之后导入的文献不会自动加入。
- 取消任意一篇后不再显示为全选。Shift 范围仍只覆盖已经加载的行，并记为部分选择。
- 改变分类或搜索会清空选择并提示。改变排序或继续滚动保留选择，后加载的行如果在快照里会显示为已选。
- 收藏、移动、删除直接按 id 执行，不把全部详情载入前端。标题翻译和 Bib 导出在点击时才按当前筛选补齐详情。
- 手动把当前筛选里的每一篇都勾上时，复选框也显示为全选。

## 方案修正

- 选择用点击当时的 id 快照，不用“筛选条件 + 排除集”的活查询。活查询会把全选之后新导入的文献算进去，和方案里“新导入不自动加入”冲突。
- 批量收藏不再跳过已经是目标状态的文献。跳过需要先读取详情；按 id 重复写入结果相同。

## 验证

- `node --test tests/paperSelection.test.ts`：快照去重、取消一篇后变为部分选择、范围选择不宣称全选、手动勾满当前总数时显示全选。
- `npx tsc --noEmit` 通过。
