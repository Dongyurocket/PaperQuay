# 2026-11-11 - PDF 存储治理预览

## 现象

阅读器来源会混入项目目录中的 PDF，文库缺少登记附件的完整性视图，现有导入命名规则也没有对应的安全预览。

## 根因

附件路径、文件身份和来源角色此前没有统一的资产记录与预览入口。

## 修改

- 增加只读登记 PDF 体检和命名预览。
- 为文库加入资产/位置数据表及持久化基础，确保普通全库保存和重开后保留已有记录；尚未自动回填历史资产。
- 阅读器来源基于已登记附件；译版语言持久化，替换译版时保留旧版记录与文件。
- 将应用版本升级到 0.4.21。

改名执行/回滚、重复文件隔离、GC、跨存储 locator 迁移和备份往返仍未完成；本版本不开放物理文件整理。

## 验证

- `npm run build` 与全部 955 项自动化测试通过。
- 桌面 UI 验收需在安装本版本后继续；0.4.20 不包含本次界面改动。
