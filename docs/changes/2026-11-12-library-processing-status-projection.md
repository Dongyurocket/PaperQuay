# 文献处理状态持久投影（P4 增量）

日期：2026-11-12
范围：工作区计划 P4 第一条纵向切片。

解析成果检查现按文献标题和登记附件身份计算来源版本并持久化。标题或附件身份变化后旧结果失效；读取时超过 24 小时的结果返回“待核实”。渲染进程分批检查并保存后回读确认版本，避免源文件变化期间的迟到结果覆盖新状态。列表、总数和全库 ID 枚举使用同一状态筛选谓词。

列表徽标现区分可用、缺失、检查失败和待核实；演示库筛选读取显式状态，未知状态不会被折叠为“未解析”。检查失败会按来源版本尽力保存为 `error`，并允许后续重试。

收到文献更新事件时，renderer 同步更新全库快照，清除这篇文献的会话内检查标记和旧徽标，再按更新后的文献对象重新核对，避免标题或附件变化后继续使用旧的界面状态。

阅读器报告解析完成时，状态按当前来源版本保存并回读确认；同一文献的后续事件会使较早响应失效。启动时会替换早期附件删除触发器定义，修复已创建过旧触发器的 SQLite 文库，而不只影响新文库。

附件删除触发器改为仅更新已有状态记录。此前级联删除附件时触发器会尝试插入状态行，在所属文献也被删除的情况下违反外键约束。
