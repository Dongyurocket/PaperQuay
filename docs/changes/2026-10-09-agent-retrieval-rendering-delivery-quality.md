# 2026-10-09 - Agent 检索范围、回答渲染与交付质量

实施及验收日期：2026-10-09 至 2026-10-10（Asia/Shanghai）。对应[实施计划](../plans/2026-10-09-agent-retrieval-rendering-delivery-quality.md)，实施验收基线为 0.4.8，发布版本递增至 0.4.9。

## 现象与根因

单篇选择与工具默认全库不一致，使模型收到未注册的引用；单波浪号范围被 GFM 解析为删除线，公式内引用链接进入数学渲染；工具前文本跨轮累积，已排队的 React 更新还能覆盖最终状态。长工具结果直接截字符串，既可能损坏 JSON，也无法解释省略了哪些材料。完整调研缺少逐文献、逐子问题台账，运行结束也没有独立的交付检查。

## 修改

| 工作包 | 实际实现 |
| --- | --- |
| W1 范围与来源 | UI 明确本轮范围优先级，服务统一有效范围；省略 ID 使用允许范围，空数组保留为空，越界 ID 返回结构化错误。查询传 documentKeys，结果再次校验本地身份；先校验、注册，再给模型 token。全库记录只补来源身份，不扩大所选范围。 |
| W2 渲染 | Agent、阅读助手、结构块正文与单块修复预览四个实际 Markdown 入口使用 `singleTilde: false`，双波浪号仍可删除。AST 消费引用占位，公式内引用移到公式旁；原始消息、occurrence 偏移和 canonical 回调保持一致，保留代码、半 token、歧义及伪造链接边界。 |
| W3 流式与终态 | 按 turn 隔离草稿，工具轮文本进入轨迹；重试清空，最终正文由最终结果提交。缓冲关闭和代际检查阻止排队更新写回终态。只保留一个最终轨迹节点，使用真实耗时；length、取消、错误和预算停止分别呈现。旧流式 meta 只依据已有终态轨迹保守恢复。checkpoint 转聊天时过滤带工具调用的 assistant 草稿及空正文，底层完整调用/应答/续取记录保留供继续执行。 |
| W4 工具预算 | 结构化结果按完整记录/段落预算，保持合法 JSON 与完整 token。正文续取绑定版本、偏移、范围；超过 5 篇返回待处理列表。原子 token 大于页面预算时明确返回续取错误和所需字符数，避免空页及偏移停滞。 |
| W5 覆盖与继续 | 完整综述自动路由至现有 comparative-survey，尊重钉选。台账分别记录候选、摘要、正文检索、重点阅读、最终引用、无关、未解决、失败及待处理，并保存子问题缺口、未合成摘段和 canonical 来源。取消先收拢已完成并发结果，再保存 checkpoint；继续沿用原范围与台账。空合成、length、没有当前子问题有效引用或引用非法时保持部分完成，保存摘段、旧研究笔记和实际用量，恢复成功才清空待合成上下文；中断报告使用本地部分结果。 |
| W6 交付与检查 | 检查所需章节、正式段落、未闭合内容、内部协议泄漏、工程条件及过强研究空白；支持“章节包括1.1…”无空格要求和历史续写，按精确编号匹配，普通 Mach 1.2 不作为章节。代码围栏内标题不能冒充正式章节。主动内容检查拆分复合主张，优先执行数字/单位、比较、否定、因果、适用条件和强空白核验，最多 48 次、并发 3；只排序执行队列，保留原始 span、绑定与主张顺序。预算外、失败或非法响应保持未知，部分主张支持不使复合句整体通过；有效来源仍可查看，笔记审批与证据门禁独立。 |

同批写工具部分失败时保留已成功生成的审批计划并说明失败调用；每个 callId 都有合法工具应答。多份笔记操作合并，当前单卡契约不能容纳的多份记忆计划在执行前整体拒绝并允许模型重新提交，不静默丢弃计划。

默认单次综述预算为 40 篇、6 个子问题、200,000 tokens、15 分钟。显式继续更新本次预算基线，累计用量保留；在已进行的单次模型请求返回后才能计入其实际用量。RAG 每次 topK 仍为 12，只提供确定性查询批次并由 registry 去重，没有 snapshot、offset 或 cursor 分页；需要更多材料时缩窄查询，或使用 `request_paper_context` 的正文版本/offset 续取。这是计划 W4.3 允许的底层无稳定游标实现，不把切片或摘段阅读计为全文通读。

桌面抽查还发现阅读器页数与当前 PDF 生命周期不同步：父层独立清零，缓存标签激活时未重报页数，页数变化又改变布局回调身份而触发同源重载，使连续来源跳转不能稳定重放。`PdfViewer` 与 `DocumentReaderTab` 改为只消费当前 PDF 源/数据的页数快照，缓存激活时同步页数，并稳定进度回调身份；同篇不同页引用已复验。

详细覆盖契约见[覆盖台账记录](2026-10-09-agent-survey-coverage-ledger.md)。
