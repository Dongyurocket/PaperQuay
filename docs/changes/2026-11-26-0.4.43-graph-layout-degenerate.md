## 1. P1-03 图谱节点与边全部画出，但坐标共线

### 现象

- 图谱不再崩溃，196 节点 / 845 边全部绘制，canvas 非透明像素 0 → 2,056，首帧 124ms。
- 但整张图挤成一条 45° 斜线：节点圆点与标签沿对角线堆叠，几乎无法阅读；16 个孤立节点另排成一条横线。

### 根因

`src/features/graph/graphLayoutMessages.ts` 的 `buildFcoseLayoutOptions` 固定 `randomize: false`。

fcose 在这个取值下走 pure-incremental 分支：不做谱初始化，只沿既有弹簧松弛。worker 在节点没有历史坐标时按黄金角螺旋给出初始位置，但该螺旋对 fcose 只是松弛起点；一旦初始配置退化（或全部为 0），结果保持一维。此时所有节点满足 x === y，主连通分量（180 节点 / 845 边）的次轴标准差为 0。

Node 复现（60 节点 / 150 边，同一份 `buildFcoseLayoutOptions`）：

| 取值 | 主轴 | 次轴 | 次轴/主轴 |
| --- | --- | --- | --- |
| `randomize: true`（全量） | 232 | 215 | 0.927 |
| `randomize: false`（增量） | 298 | 0.00 | 0.000 |

安装版实测：节点坐标 `(886,886) (836,836) (710,710)`，PCA 主次轴比 1.2e14。

### 修改

- `buildFcoseLayoutOptions`：`randomize: extra.incremental !== true`。全量布局让 fcose 自己做谱初始化；增量刷新保持 `randomize: false`，新增节点不整体重排（已验证：已有二维布局在增量刷新后主次轴保持 219/212）。
- `graphLayout.worker.ts`：注释说明黄金角螺旋只作增量布局的松弛起点。
- 局部图谱与主线程回退路径共用同一构造函数，一并恢复二维铺开。

### 验证

- `tests/graphLayoutDegenerate.test.ts`：真实 fcose 跑全量布局，断言次轴/主轴 > 0.05；在 0.4.42 的取值下必失败（实测 0.000）。
- `tests/graphLayout.test.ts`：全量断言 `randomize === true`，增量断言 `randomize === false`。
- 质量门：typecheck 6 项目 0 诊断、lint 0 error / 205 warning、build 通过、`npm test` 1,573 项（1,563 过 / 10 跳过 / 0 失败）。
