# P4：论文概览页

2026-11-17，分支 `ui/p4-overview`，基于 `main` 的 `5de3fb7`（已发布 0.4.28）。本轮只调整概览界面及其所需的状态、缓存和确认接线，没有修改版本号、提交、推送或发版；没有修改 library、知识库或 RAG 的 schema / `user_version`，没有访问用户真实文库。

## 界面与交互

- 标题与操作按钮上下排列。标题使用整行宽度，最多三行并提供全文悬停提示，下方显示作者、年份、期刊和所在文库或分类。「进入阅读」为唯一主按钮。
- MinerU 解析、全文翻译和生成概览统一进入共享 `Menu` 的「处理」菜单，逐项显示完成、进行中或失败状态。进度沿用 P3 `getPaperTaskProgress`，未知总数保持不确定进度。翻译运行时保留取消入口。
- 页面徽标和「AI 概览」标题保留，删除说明性副标题、大号「概览已生成」徽标及分节正文中重复的大写标题。生成状态、关键词数、发现数和刷新按钮集中在卡片标题行。
- 有内容的概览、背景、问题、方法、实验、发现、结论、局限分节才显示标签；发现使用语义列表。分节解析是独立纯函数，兼容结构化缓存、中文/英文/双语 Markdown 标题、缺节、无标题正文及代码围栏。
- 文件卡改为紧凑键值列表，显示原始 PDF、译版 PDF、MinerU 结果和结构块数。每项复用 P1 的路径解析、存在性检查与「在文件夹中显示」逻辑；缺失项禁用。为独立 PDF 补充 reader workspace 身份和已打开 JSON 路径选项，不持久化临时文献适配对象。
- 没有缓存时显示模型配置状态与生成入口。未配置概览模型时提供「模型设置」，禁止发起生成；PDF 文本模式不要求先存在 MinerU 结构块。缓存读取、文档加载和模型生成分别显示对应状态。
- 概览页及共享 SummaryPanel 使用现有 `--pq-*` 令牌，控件 8px、卡片 12px。修改覆盖助手栏共用的 compact 分支，支持 280px 宽度、长标题及空状态；分节标签支持方向键、Home 和 End。

## 缓存与额度确认

普通打开、自动恢复和普通生成仍优先读取缓存，不依赖模型配置。只有用户确认「重新生成」后才传递 `force: true` 跳过缓存并调用模型；生成失败保留原概览。刷新和重新解析都使用现有 `ConfirmHost`，说明额度消耗。

确认期间避免重复操作；关闭或切换文档后，旧确认结果不再触发回调。确认通过时重新核对当前任务忙碌状态、模型/正文可用性和最新回调。

旧缓存迁移和新概览保存共用 `overviewCacheWrites.ts` 的串行写入队列。尚未开始的过期迁移会跳过；已经开始的迁移先完成，再保存新生成结果，避免迟到的旧缓存覆盖新结果。单次写入失败不会堵塞后续保存。该调整只作用于既有概览缓存文件。

概览模型配置通过单独的 `overviewConfigured` 接线。阅读选区等已有功能继续使用原来的 `aiConfigured`，避免概览模型未配置时隐藏仍可使用 Agent/QA 模型的提炼操作。

## 引导锚点与方案差异

- 保留 `overview-actions`、`overview-mineru-parse`、`overview-translate-document`、`ai-summary`。两个处理动作锚点放在「处理」按钮的可见包装元素上，菜单关闭时仍有可见目标，点击可打开菜单。
- 文库详情的同名锚点分别改为 `library-mineru-parse`、`library-translate-document`、`library-generate-summary`；文库外层使用 `library-ai-summary`。JSX 契约测试检查文库与阅读器命名不重叠，避免全局选择器误指文库详情。
- 当前基线已在 `5adc5e3` 移除 `OnboardingGuide` 及其运行接线。检查了 App、ReaderWorkspace、readerPreferencesContent 等位置，当前仅余锚点，没有可启动的完整引导流程。本轮验证锚点保留、可见性与隔离，不恢复已删除的引导功能。
- 当前助手栏仍导入/导出共享 SummaryPanel，但已没有挂载 compact 概览的活动入口。因此用真实共享组件的浏览器夹具和组件行为测试覆盖 compact 分支，没有增加新的助手栏导航。
- 1040px 宽度下文件卡排在概览下方；1200px 起使用右侧 280px 文件卡，保证标题与正文阅读宽度。

## 独立审查与反驳复核

由两个独立方向审查：版式/主题/可访问性，以及逻辑/回归。逐条检查触发条件，结果如下。

| 发现 | 反驳复核与处理 |
| --- | --- |
| 确认时禁用刷新按钮，Esc 后焦点回到 BODY | 浏览器键盘复现成立。确认期间改用 `aria-disabled`，只在功能确实不可用时原生禁用；取消后焦点返回刷新按钮。 |
| 「处理」菜单缺少可访问名称 | 复核共享 Menu 从 trigger 的 aria-label/title 派生名称，发现成立。添加本地化 aria-label，浏览器验证 `menu "Process"`。 |
| 缓存读取被读成「生成中」 | 发现成立。新增可选 loadingLabel，分别显示读取缓存、加载文档、生成概览。 |
| PDF 文本模式零 MinerU 块时生成被禁用 | 旧判断确有问题；接入 `summarySourceReady` 后，PDF 文本模式按 PDF 来源判定。组件浏览器验证按钮可用。 |
| 迟到的被动旧缓存迁移覆盖强制生成结果 | 独立内存时序复现成立。共用串行 writer 并在写入启动前检查请求有效性；新增三项顺序/失效/失败恢复测试，另一审查者复核通过。 |
| 确认弹窗在文档卸载后仍调用旧动作；忙碌后确认仍能执行 | 处理菜单和共享卡片的 handler 级复现成立。增加生命周期及当前资格保护；按 workspace 身份重建组件，补充确认期间卸载、更新状态和回调的测试。 |
| summaryConfigured 误用于阅读选区的 AI 能力开关 | 复核选区提炼实际解析 Agent/QA 模型，发现成立。增加单独 overviewConfigured 接线，选区保留原来的配置判断；另一审查者复核通过。 |

其他文件定位适配、缓存优先显示、失败保留内容、主题对比度和分节行为未发现剩余可操作问题。
