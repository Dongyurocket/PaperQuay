# 2026-10-09 - Agent 正文顺序编号与片段级参考文献

## 现象

Agent 正文引用显示运行内检索编号，正文后的证据区域按论文和页分组。同篇同页的多个证据片段可能被合并，正文顺序与列表顺序也不一致。

## 根因

原展示直接使用 registry label，并用按论文/页聚合的模型展示证据。逐次引用核验已经存在，但正文、核验明细与文末列表没有共享回答级显示编号。阅读器原先还会把同页其他正文块作为结构块定位兜底，容易让页面定位看起来像精确片段定位。

## 修改

- 新增 `buildAgentAnswerReferences()` 派生模型：按原始正文偏移扫描，仅给已核验出现分配连续编号；同 ID 复用，不同 ID 保留。原 token、正文、canonical label、绑定偏移和持久化格式不变。
- 正文用紧凑数字按钮；核验明细共享同一编号，失败出现按位置显示原因。正文和列表回调传原始 canonical 对象，显示编号另传。
- 用完整有序的轻量参考文献列表替代本消息原证据分组；保留题名、PDF 页序和片段预览，长片段单独展开。同页长预览从不同处显示；预览完全相同则补充结构块或证据身份提示。核验信息、检索材料排在列表之后。
- 共享提示要求模型只复制证据 token，不手写数字或参考文献附录。流式半 token 隐藏内部 ID；待核验、中断、失败及 legacy 数字不升级为可信链接。
- Agent 阅读器跳转等待 PDF 页数及原结构块恢复，校验页码范围，仅命中唯一原结构块；重复 block ID 降级，缺引用页码时可使用唯一结构块的可靠页码。精确结构块没有 bbox 时，结构区定位该块，PDF 同步到整页。旧 block、不可靠位置、整页占位 bbox 明确降级；错误页码不钳制到另一页，PDF 不可用时提示重试。PDF 打开失败与解析错误分开处理，解析失败仍允许可靠页码定位。既有笔记跳转策略保留。
- 桌面日志暴露后端事件白名单缺少已有 `citation_verification` 类型，已补齐并验证事件及后续运行记录可保存。
